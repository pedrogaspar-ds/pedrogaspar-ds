After submitting it I audited my own result. The model behind that number had been trained on the test years. I re ran it with a control trained only on 2010 to 2022, added thirty seeded retrainings, made the cash accounting consistent across every strategy, and ran formal Sharpe ratio tests. The agent beats nothing at the 5 percent level, and its low drawdown came from sitting in cash on 472 of 499 days. The repository is that audit, written up in full.
